## Самопроверка инструментов (tests/harness, tests/capacity/test_selftest.py)

Клиент, манифест, профиль, фикстуры, оракул квот, разбор ошибок и решение
сборщика — 48 офлайн-тестов. В том числе:

- 413 `text/plain` попадает в `record["error"]`, а не в `None`;
- 200 с обрезанным JSON списка даёт `complete=false`;
- `tools/collect.py` блокирует GO при отсутствии обязательного кейса и при
  его статусе skip / incomplete / observation;
- `tools/report.py` повторно проверяет обязательные кейсы перед GO.

## Решение о прогоне

Обязательные кейсы — `required.cases` профиля. `tools/collect.py` получает
профиль аргументом `--profile` (`make report` передаёт его автоматически);
при отсутствии профиля список берётся из `required_cases` манифеста. Пустой
список обязательных кейсов даёт HOLD.

## Независимая оценка безопасности

Сетевой пентест агенту не поручается. Задание специалисту — `docs/pentest-brief.md`.
В инженерном отчёте от 24 ноября приведены [выводы внешней проверки](../reports/developer.md#handoff). Если для новой сборки требуется отдельное заключение, эта часть приёмки остаётся открытой.
